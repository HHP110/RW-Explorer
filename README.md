# RW Explorer - RailWorks 文件资源管理器

![RW Explorer Logo](logo.png)

一个基于 WPF 开发的 RailWorks 文件资源管理器工具，提供便捷的文件浏览和管理功能。

## 功能特性

- 浏览 RailWorks 游戏文件结构
- 预览文件内容
- 支持多种文件格式
- 用户友好的界面
- 可扩展的架构

## 技术栈

- WPF (Windows Presentation Foundation)
- Microsoft.Web.WebView2
- Newtonsoft.Json
- WindowsAPICodePack

## 安装与使用

### 系统要求
- Windows 10/11
- .NET Framework 4.7.2 或更高版本
- RailWorks 游戏安装

### 安装步骤
1. 下载最新版本 [Release](https://github.com/HHP110/RW-Explorer/releases)
2. 解压到任意目录
3. 运行 RWExplorer.exe
